# Rajab Portfolio — Clean Fixed Version

FILES
-----
index.html
style.css
script.js

OPTIONAL IMAGE
--------------
Put your profile photo in the same folder and name it:

ismail Rajab.png

The page has a fallback "IR" card if the photo is missing.

IMPORTANT
---------
Do not paste CSS or JavaScript directly into the visible HTML text.

The developer/code fragments in the hero are intentional decorative HTML
elements inside .code-background. They are styled behind the hero content,
so they do not appear as broken/raw code.

GITHUB PAGES
------------
Upload index.html, style.css and script.js together in the same folder.
Upload the profile image too if you want your photo to appear.


IMAGE FOLDERS
-------------
Create this folder beside index.html:

images/

Then put your project images inside it:

images/ka-body.jpg
images/warr-gamer.jpg
images/rajbunny.jpg
images/marquee-bg.jpg

PROJECT IMAGE + DESCRIPTION
---------------------------
Each project is inside a <article class="project-card"> in index.html.

Replace the image filename in:
<img src="images/ka-body.jpg" ...>

Change the project description inside:
<p>YOUR PROJECT DESCRIPTION HERE</p>

MARQUEE BACKGROUND
------------------
Put your preferred background image here:

images/marquee-bg.jpg

The CSS automatically uses that image behind the marquee with a dark green
overlay so the white marquee text remains readable.
